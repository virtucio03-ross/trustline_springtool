# Developer Setup

1. Install Node.js 24 or newer.
2. Install Rust and the Stellar CLI for contract builds.
3. Copy `.env.example` to `.env`.
4. Run `npm install`.
5. Run `npm run db:migrate`.
6. Run `npm run db:seed`.
7. Run `npm run dev`.

The generated scaffold is wired for Stellar testnet and Trustline Spring Cleaning Tool.
